# Trendory – Online Fashion Shopping Website

## 📌 Project Overview

**Trendory** is a front-end online fashion shopping website designed to provide users with a simple and user-friendly shopping experience.

The website includes fashion products, product categories, shopping features, customer forms, and supporting pages such as cart, wishlist, login, tracking, and returns.

This project was developed to gain practical experience in **web development, user interface design, JavaScript functionality, and website testing**.

---

## ✨ Features

* 🏠 Home page with fashion-focused hero section
* 👗 Clothing collection

## 🧪 Testing

The website can be tested using **manual testing techniques** to verify functionality, usability, navigation, and form validation.

### Sample Test Scenarios

| Test Scenario                        | Expected Result                                    |
| ------------------------------------ | -------------------------------------------------- |
| Open the website                     | Home page should load successfully                 |
| Click Home                           | User should navigate to the Home page              |
| Click Shop                           | Shopping/product section should open               |
| Select a product                     | Product details should be displayed correctly      |
| Click Buy Now                        | Customer order form should open                    |
| Submit order form with valid details | Order confirmation/process should work as designed |
| Submit form with missing details     | Appropriate validation should be displayed         |
| Open Cart                            | Cart page should load correctly                    |
| Open Wishlist                        | Wishlist page should load correctly                |
| Open Login                           | Login page should open                             |
| Open Track Order                     | Order tracking page should open                    |
| Open Return & Exchange               | Return information page should open                |
| Test navigation links                | Links should navigate to the correct pages         |
| Test payment interface               | Available payment options should be displayed      |
| Test Contact form                    | Contact form should accept valid information       |

1. Clone or download this repository.

3. Open `index.html` in a web browser.
4. Navigate through the different sections and pages.
5. Test the available website functionality.

No server setup is required for the basic front-end version.
